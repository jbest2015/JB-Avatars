# Symmy — Printing Guide

**Parts:** FrontShell + BackShell (red), FaceBlock (white), 3 Spikes (ORANGE filament), Base (any).
Shells seam-face down (supports on interior ceiling cap only); FaceBlock flat back down; spikes flat; Base flat.
**Assembly:** FaceBlock into window -> three spike tabs into crown slots (clamped at close) ->
snap BackShell -> right-side tail into Base dish. 0.25 mm tolerances. Face = Sharpie guides.
