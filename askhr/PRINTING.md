# AskHR — Printing Guide

**Parts:** FrontShell + BackShell (teal), FaceBlock (white), CrestCenter (teal),
CrestLeft + CrestRight (ORANGE filament), Base (any).
Shells seam-face down (supports on interior ceiling cap only); FaceBlock flat back down;
crest spikes flat; Base flat down.
**Assembly:** FaceBlock into window -> three crest tabs into crown slots (clamped at close) ->
snap BackShell (lip + posts) -> left-side speech-bubble tail into Base dish.
0.25 mm snap tolerances. Face = Sharpie guides. Speech-bubble body, tail bottom-left per badge art.
