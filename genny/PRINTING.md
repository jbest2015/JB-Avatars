# Genny — Printing Guide

**Parts:** FrontShell, BackShell (purple) - FaceBlock (white) - Antenna (purple) - Base_optional (any color)

| Part | Orientation | Supports |
|---|---|---|
| FrontShell | seam face down | interior ceiling cap only |
| BackShell | seam face down | interior ceiling cap only |
| FaceBlock | flat back down | none |
| Antenna | lying on its side | none |
| Base | flat side down | none |

**Settings:** 0.16-0.20 mm layers, 15-20% infill, walls >= 3 perimeters.
**Assembly (no glue):** 1) Set FaceBlock into the front shell window from inside (its curved bulge self-centers). 2) Lay the Antenna stem in the crown half-groove, anchor ball inside. 3) Snap BackShell on - its lip slides inside the front shell, posts press the face block. 4) Drop the tail tip into the Base dish.
**Snap fit:** 0.25 mm tolerances. If tight, light sanding on the lip; if loose, a dot of glue.
**Face:** eye/smile recesses are Sharpie stencil guides.
