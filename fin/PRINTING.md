# Fin — Printing Guide

**Parts:** FrontShell + BackShell (dark green), FaceBlock (white), Crest (green), Tie (gold), Base (any).

| Part | Orientation | Supports |
|---|---|---|
| Front/BackShell | seam face down | interior ceiling cap only |
| FaceBlock | flat back down | none |
| Crest | lying flat | none |
| Tie | flat back down | none |
| Base | flat down | none |

**Assembly:** FaceBlock into window from inside -> Crest tab into crown slot -> Tie tab into the front
slot under the window (both clamped when shells close) -> snap BackShell -> tail into Base dish.
The V-collar lines are engraved on the front shell as Sharpie guides; $ on the coin is recessed.
0.25 mm snap tolerances. ~104 mm tall assembled.
