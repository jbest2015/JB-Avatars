# Vera (Snap-Fit) — Printing Guide

**Parts:** FrontShell + BackShell (purple), FaceBlock (white), CrestBase (white), Chart (purple), Base (any).

| Part | Orientation | Supports |
|---|---|---|
| Front/BackShell | seam face down | interior ceiling cap only |
| FaceBlock | flat back down | none |
| CrestBase | flat top down | none |
| Chart | lying flat (Y face down) | none |
| Base | flat down | none |

**Assembly:** FaceBlock into front window from inside -> Chart tab through CrestBase hole into the crown slot
(clamped when shells close) -> snap BackShell (lip + 4 posts) -> tail tip into Base dish.
0.25 mm snap tolerances; sand lip if tight. Eyes/smile are Sharpie guides. ~103 mm tall assembled.
