# Vera — Printing Guide (12-part kit + ThreePiece variant)

**ThreePiece/** (simplest): Front + Back solid halves (purple) + FacePlate (white).
Print halves flat-face down, no supports; 3 alignment pegs snap the halves together; glue recommended.
Sharpie the face using the recessed eye/smile guides. Base catches the pin tip.

**Full kit:** Body, Head, FacePlate, Eyes, Mouth, EarL/R, ArmL/R, ChartCard, ChartBars, Base.
All parts have flat backs or seats; arms print with minor supports at the shoulder cut.
Multi-color: purple body/head/arms, white plate+card, black eyes/mouth, purple bars.
