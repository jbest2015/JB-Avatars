# Theo (Snap-Fit) — Printing Guide

**Parts:** FrontShell + BackShell (teal), FaceBlock (white), Bell (gold), BowTie (gold/orange), Base (any).
Shells seam-face down (supports on interior ceiling cap only); FaceBlock flat back down;
Bell dome-up on its disk (no supports); BowTie flat back down; Base flat.
**Assembly:** FaceBlock into window -> Bell tab into crown slot -> BowTie tab into the front slot
below the window (both clamped when the shells snap) -> BackShell on -> tail into Base dish.
0.25 mm tolerances. Face = Sharpie guides. Replaces the old glue-together kit in theo/.
