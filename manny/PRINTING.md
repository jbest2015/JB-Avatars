# Manny — Printing Guide

**Parts:** FrontShell + BackShell (blue), FaceBlock (white), Crest = open book + antenna (teal), Base (any).

Shells seam-face down (supports only on interior ceiling cap); FaceBlock flat back down;
Crest lying flat on its back (book pages + stem + ball print in-plane, no supports); Base flat down.

**Assembly:** FaceBlock into window -> Crest tab into crown slot (clamped at shell close) ->
snap BackShell -> tail into Base dish. 0.25 mm tolerances. Eyes/smile are Sharpie guides.
