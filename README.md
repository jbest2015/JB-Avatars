# JB Avatars — 3D Printable Mascot Crew

Snap-fit, FDM-printable robot mascot figurines modeled in Blender 5.2.
All STLs in millimeters, ~100-105 mm tall assembled. Each character folder contains STLs,
the .blend, reference art, and a PRINTING.md guide.

## Printing (all characters)
Shells print seam-face down with supports only on the interior ceiling cap; face blocks,
toppers, and bases print flat with no supports. 0.16-0.20 mm layers, 15-20 % infill.
Face features are recessed Sharpie stencil guides. Every part verified watertight
(zero non-manifold edges). Toppers mount via tabs clamped into slots when shells snap shut.
Display bases catch each character's bottom point in a recessed dish.

`renders/` holds review renders.
